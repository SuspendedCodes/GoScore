# GoScore icons

The SVG icons in this folder (`cricket.svg`, `football.svg`, `monitor.svg`, `scorecard.svg`, `settings.svg`) were drawn specifically for GoScore and are original project assets. They are not downloaded from a third-party icon pack, so no third-party attribution or icon-pack licence is required.

The interface avoids emoji glyphs because their appearance varies across Windows, browsers and OBS Chromium builds. For a future release that imports third-party icons, keep the exact source URL and licence notice here before shipping them.
